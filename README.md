# tacode

貯金目標トラッカー - 野望を叶えるための貯金管理アプリ

## 機能

- 複数の貯金目標を管理
- 入金履歴の記録・棒グラフ表示
- 達成予測・統計ダッシュボード
- ダークモード対応
- 紙吹雪エフェクト（目標達成時）
- 日にちカウンター（経過日数・カウントダウン）
- 目標ごとのリマインダー通知
- メモ機能
- PWA対応（オフライン使用可能）

## 技術スタック

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 4
- Lucide React（アイコン）
- ローカルストレージによるデータ永続化

## 開発環境のセットアップ

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
